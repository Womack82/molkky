# Mölkky – Compteur de points

Application web, pensée pour le téléphone, pour compter les points d'une partie de Mölkky.

## En ligne

https://womack82.github.io/molkky/

## Installer l'app sur le téléphone

L'app s'installe comme une application et fonctionne ensuite sans réseau (au bord du terrain).

- **iPhone** : ouvrir l'adresse dans **Safari**, toucher **Partager**, puis **Sur l'écran d'accueil**.
- **Android** : ouvrir l'adresse dans **Chrome**, toucher le **menu ⋮**, puis **Installer l'application**.

## Ouvrir en local

Ouvrir le fichier `index.html` dans un navigateur (double-clic). Aucune installation n'est nécessaire.
L'installation et le mode hors ligne ne fonctionnent qu'avec l'adresse en ligne.
